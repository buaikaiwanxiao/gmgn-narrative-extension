# GMGN 叙事雷达（Chrome 插件）

在 GMGN 的战壕卡片、搜索结果和代币详情页上，直接标出：

- **叙事次序**：本波同名叙事第一个标「新」（搜索结果里标「1」），其余标 2、3…；只知道下限标「≥k」；更早一波或老盘标「旧」；查不到标「?」。
- **发射台**（BSC：four / Flap / Pancake / Uni；Solana：Pump / Mayhem / Bonk / LaunchLab / Meteora）和**底池计价币**（BNB / USDT / USD1 / CAKE / SOL / USDC …），大字彩色显示。
- 支持 BSC 和 Solana。
- **蓝色数字**：用这张盘的 ticker 在 GMGN 搜索时它排第几。点一下会打开 GMGN 搜索框并填好 ticker。
- **→1号**：一键打开本叙事第一个盘的 GMGN 页面；第一个盘整张卡红框高亮。

插件只读页面、只做标注，不下单、不连钱包、不做任何交易。推送弹窗、顶部滚动条、持仓列表等位置不会加标注。

## 安装

1. 下载 zip 并解压到一个**固定的文件夹**（以后升级也用这个文件夹）。
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压出来的文件夹。

## 首次配置（只需一次）

装好后会自动打开设置页：

1. 填「服务地址」和「访问密钥」。这两样找给你发插件的管理员要，每人一把密钥。
2. 点「测试连接」，显示「连接正常」就好了。
3. 打开 gmgn.ai 的战壕或搜索，就能看到标注。

设置页以后也可以点工具栏里的插件图标打开。

## 升级（设置不会丢）

1. 下载新版 zip，解压后**覆盖原来那个文件夹**里的文件。
2. 到 `chrome://extensions` 找到本插件，点「重新加载」（圆形箭头）。

注意：

- **不要「移除」后再重新加载。** 移除会清掉已填的服务地址和密钥，需要重新填一次。
- 插件 ID 是固定的，所以即使移除后重装，ID 也不变，但已填的设置一样会被清掉。
- 设置只存在本机浏览器里，不会同步到 Google 账号。

## 常见问题

- **标注全是「?」，悬停提示「访问密钥缺失或无效」**：密钥填错或已被作废，找管理员要新的。
- **悬停提示「连不上服务地址」**：服务地址可能换了，找管理员要新地址，填进设置里保存即可，密钥不用改。
- **悬停提示「请求太快」**：每把密钥有频率限制，稍等片刻会自动恢复。
- **Solana 的「第几次」偏少**：Solana 上 LaunchLab（含 Bonk）和 Meteora 的盘只从 2026-11-26 起开始收录，更早的同名盘不计入，所以第几次可能偏少；Pump.fun 的盘有近 7 天的数据。

## 隐私

- 访问密钥只存在本机浏览器的扩展存储里，只发给你填写的服务地址。
- 蓝色数字是插件在你自己的浏览器里，用你当前的 GMGN 页面去查 GMGN 搜索得到的（按 ticker 合并、缓存 5 分钟、每秒最多 1 次）。
- 不读取钱包、不读取 GMGN 登录信息之外的任何数据，也不上传你的浏览记录。
